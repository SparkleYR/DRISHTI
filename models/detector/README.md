# Phase 2 detector asset

The active detector is Ultralytics YOLO11n (`yolo11n.pt`) under the user-approved
AGPL-3.0 path for this internal hackathon prototype.

The weight file is a development-time download and is intentionally ignored by
source control. Runtime startup must load only `models/detector/yolo11n.pt` and
must not download or contact a remote service.
