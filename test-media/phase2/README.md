# Phase 2 controlled detector checks

`ultralytics-bus.jpg` is the official Ultralytics sample downloaded from
`https://ultralytics.com/images/bus.jpg`. Its SHA-256 is
`C02019C4979C191EB739DDD944445EF408DAD5679ACAB6FD520EF9D434BFBC63`.
It provides a repeatable real-model check for `bus` and `person`.

The Phase 2 physical gate additionally requires controlled phone-camera checks
for the objects available to the team: chair, person, bag, bicycle or
motorcycle, car, and bus. Use ordinary lighting, keep the tester stationary,
capture one frame at a time, and confirm that each visible yellow box aligns
with the object. Record missed and irrelevant detections; do not stage a test in
traffic or rely on the prototype for mobility safety.
